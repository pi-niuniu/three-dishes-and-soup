## 📖 项目简介

**《四季三餐 · 好好吃饭》** 是一款专为 2 人家庭日常就餐量身打造的智能排餐与做饭协同微信小程序。

告别“今天吃什么”的每日纠结，拒绝千篇一律的外卖，一键生成荤素搭配合理、营养均衡的时令菜单；自动合并换算菜市场口语化斤两清单，并支持一键生成微信卡片分享给做饭大厨或家人，让家庭做饭与食材采购变得省心、体贴、高效。

本项目采用**纯前端无服务器架构**，所有菜单生成、偏好设置、历史记录与采购清单均保存在本地存储（`Storage`），无需购买云服务器与域名，导入即可开箱即用。

## ✨ 核心亮点与场景设计

### 1. 👫 常住 2 人家庭午晚两顿份量保障
- **1.8x 科学放大基准**：按中午上门做一顿、两人共享午餐加晚餐的分量设计，保证每餐菜量充盈宽裕；
- **菜市场口语化斤两换算**：告别冷冰冰的“350g/480g”，自动折算为菜市场沟通习惯：
  - “1 斤 2 两 (约 600g)”、“半斤 (约 250g)”、“1 斤半 (约 750g)”
  - 蔬菜按“1 把 (约 1 斤)”、豆腐“1 盒 (或 1 块)”、大蒜“1 头”、生姜“1 块”、蒜苗“1 小捆”。

### 2. 🍲 四大高频就餐模式
- 🍲 **3 菜 1 汤**：1大荤 + 1小荤/蛋豆 + 1时蔬 + 1靓汤（标准满血家庭餐）；
- 🍲 **2 菜 1 汤**：1荤 + 1素 + 1汤（轻量舒心日常款）；
- 🍱 **3 个菜**：1大荤 + 1副荤/蛋豆 + 1时蔬（无汤快捷快手组合）；
- 🍳 **3 个炒菜**：全热炒干香搭配，爆炒/清炒相宜，下饭开胃。

### 3. 🧠 深度优化算法引擎
- **多样性抽样（Softmax-like Weighted Sampling）**：引入带权随机抖动，打破高分招牌菜（如回锅肉）的永久垄断，每次重新搭配均能发掘时令美味；
- **单菜锁定机制**：点击“🔒 锁定”心仪菜品后，点击“🔄 重新搭配”时已锁定菜品 100% 原位保留；
- **单槽位换菜防乒乓**：槽位级排除记忆队列，连续点击“🔄 换一个”时按序轮换候选菜，绝不在两道菜之间交替死循环；
- **同桌生鲜农产品硬性互斥**：统一归一化生鲜蔬菜键值（西红柿/番茄、豆腐、土豆、莲藕等），同一餐桌严格杜绝“西红柿炒蛋 + 西红柿蛋汤”或“土豆烧牛肉 + 土豆丝”撞菜。

### 4. 🛒 双视图协同与微信免密分享
- **🍳 厨师做饭看板**：查看做饭菜谱明细、分类标签、总做饭耗时与烹饪建议；
- **🛒 采购买菜清单**：按品类智能归类合并食材采购总量，支持打勾划线；
- **双独立贴心便签**：
  - 【给大厨的做饭叮嘱】：附带“少放盐”、“少放油”、“微辣即可”等快捷标签；
  - 【给大厨的买菜特别交代】：附带“家里有葱姜蒜不买”、“青菜要嫩叶”等快捷标签；
- **📲 微信卡片极速分享**：设计紧凑轻量的序列化参数机制，分享 URL 小于 900 字符，大厨在微信中点击卡片秒开完整菜单与采购清单，免登录即开即用。

## 🚀 快速上手与本地调试

### 1. 环境准备
- 下载并安装最新版 [微信开发者工具 (macOS / Windows)](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)；
- 本地安装 Node.js 18+。

### 2. 导入与真机运行
1. **克隆项目到本地**：
   ```bash
   git clone https://github.com/pi-niuniu/three-dishes-and-soup.git
   cd three-dishes-and-soup
   ```

2. **安装开发依赖（可选，用于测试与 TypeScript 编译）**：
   ```bash
   npm install
   ```

3. **导入微信开发者工具**：
   - 打开微信开发者工具，选择 **「导入小程序」**；
   - **目录**：选择本项目克隆后的根目录；
   - **AppID**：可填入您自己的个人小程序 AppID，或者直接点击选择右侧 **「测试号」** 进入；
   - 点击 **「确定」** 导入。

4. **真机扫码预览**：
   - 点击开发者工具顶部工具栏的 **「预览」** 按钮；
   - 使用微信扫描弹出的二维码，即可在手机微信上实时体验！
